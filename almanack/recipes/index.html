How to add a new recipe

  1. Open almanack/recipes/recipes.json in your repo (you can edit it right on GitHub).
  2. Copy the template below and add it to the "recipes" array (mind the comma between entries).
  3. Commit and push. The page auto-renders from the JSON — no HTML editing needed.
{
  "id": "your-recipe-slug",
  "title": "Recipe Name",
  "description": "One or two lines on why it's good.",
  "category": "Mains",
  "tags": ["vegetarian", "quick"],
  "time": "30 min",
  "serves": "2",
  "components": [
    {
      "name": "Main",
      "ingredients": ["1 cup something", "Salt to taste"],
      "steps": ["Do this.", "Then that."]
    }
  ],
  "serving": "How to serve it (optional).",
  "notes": ["Any tips or variations (optional)."]
}

Components: use one component for a simple dish, or several (e.g. dough, filling, dip) for multi-part recipes. Category becomes a filter button automatically (Breakfast, Mains, Snacks, Desserts, Drinks…). Only title and components are required.
